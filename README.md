# LifecycleIQ: Customer Intelligence Platform

LifecycleIQ is an end-to-end MarTech analytics project that predicts customer churn, estimates customer lifetime value, recommends next-best marketing actions, and simulates campaign ROI.

## Business Problem

Marketing teams need to identify high-risk and high-value customers so they can prioritize retention campaigns and avoid wasting incentives on customers who are unlikely to generate value.

## Dataset

This project uses the Olist Brazilian E-Commerce public dataset, containing customer, order, payment, review, and product data.
